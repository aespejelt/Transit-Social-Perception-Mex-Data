# Transit-Social-Perception-Mex-Data
Social perception data about public transport in México
################################# 
This database was established by Dr. Angelina Espejel for the study of public transport in México. For any questions regarding the dataset or to request permission for its use, please send an email to: angelina.et@gmail.com

This dataset gathers opnions collected from social networks (X) about several public transport services in México.
